# 架构说明

> 本文档描述「云上浏览器开发环境」在华为云上的技术架构、资源清单与访问方式。

## 1. 总体架构

本实践在华为云上创建一台公网可达的弹性云服务器（ECS），实例首次启动时通过用户数据脚本自动完成以下工作：

1. 安装浏览器版 VS Code（`code-server`，监听 8080 端口，启用密码认证）；
2. 安装 Node.js 运行时（通过 `nvm`，版本 `20.11.0`）；
3. 以 systemd 服务方式启动 `code-server` 并设置为开机自启。

> 若使用预置私有镜像（变量 `private_image_id`，由 `infra/image-bake/` 烘焙栈产出），
> 上述安装步骤已随镜像完成，开机脚本仅写入配置并启动服务，分钟级就绪；
> 两种路径共用同一份用户数据脚本（按 `command -v` 自动判断是否跳过安装）。

开发者从任意设备的浏览器访问 `http://<弹性公网IP>:8080`，输入访问密码即可获得完整的云端开发体验。

## 2. 资源清单

| 资源 | Terraform 资源类型 | 作用 |
|-|-|-|
| 私有网络 | `huaweicloud_vpc` | 承载实例的私有网络（`10.0.0.0/16`） |
| 子网 | `huaweicloud_vpc_subnet` | 实例所在子网（`10.0.1.0/24`，网关 `10.0.1.1`） |
| 安全组 | `huaweicloud_networking_secgroup` | 实例网络边界 |
| 安全组规则 | `huaweicloud_networking_secgroup_rule` | 入方向仅放行 TCP 8080，来源为 `allowed_cidr` |
| 弹性公网 IP | `huaweicloud_vpc_eip` | 对外访问入口，实例借其出网 |
| EIP 绑定 | `huaweicloud_vpc_eip_associate` | 将弹性公网 IP 绑定到实例网卡端口 |
| 弹性云服务器 | `huaweicloud_compute_instance` | 运行浏览器版 VS Code 与 Node.js |
| 镜像查询 | `huaweicloud_images_image`（数据源） | 按名称正则获取 Ubuntu 22.04 公共镜像 ID |

## 3. 访问方式

- **入口**：`http://<弹性公网IP>:8080`。
- **认证**：`code-server` 采用密码认证，密码由变量 `vscode_password` 提供，写入实例内
  `/root/.config/code-server/config.yaml`。
- **网络约束**：安全组入方向仅放行 TCP 8080，且来源受 `allowed_cidr` 约束。
  部署前请务必将 `allowed_cidr` 由默认的 `0.0.0.0/0` 收紧为本机公网 IP 或办公网段。
- **出网**：实例通过弹性公网 IP 直接出网，无需 NAT 网关。

## 4. 关键配置项

| 变量 | 默认值 | 说明 |
|-|-|-|
| `region` | `cn-north-4` | 华为云区域 |
| `availability_zone` | `cn-north-4a` | 可用区完整名称 |
| `flavor_id` | `s6.large.2` | ECS 规格（2 核 4 GB） |
| `image_name_regex` | `^Ubuntu 22.04 server 64bit$` | 公共镜像名称正则（首尾锚定） |
| `volume_size` | `128` | 系统盘容量（GiB） |
| `system_disk_type` | `GPSSD` | 系统盘类型 |
| `bandwidth_size` | `5` | 弹性公网 IP 带宽（Mbit/s） |
| `allowed_cidr` | `0.0.0.0/0` | 允许访问 8080 的源 IP 段（部署前务必收紧） |
| `vscode_password` | 无（必填） | 浏览器版 VS Code 访问密码（敏感变量） |
| `private_image_id` | `""`（留空） | 预置私有镜像 ID（`infra/image-bake/` 产出）；留空则开机自动安装 |
| `healthcheck_topic` | `""`（留空） | 可选：部署后健康检查通知主题（ntfy.sh），留空则不推送 |

## 5. 安全设计要点

- **最小端口暴露**：仅放行 8080 单端口，来源受 IP 段约束。
- **凭据安全**：访问密码以敏感变量传入，不写入仓库；华为云 AK/SK 请在「我的凭证」页面获取，并仅在本机终端设置，不落盘。
